# Dice

Dice are consumables for rerolling one clothing perk. The next release includes
acquisition through Scrapping, rarity merging and Gold Marketplace trading.
There are five Dice rarities, E–A. Common clothing has no perks, so there is
no Common Dice.

## Acquisition And Weight

Scrapping Uncommon or higher clothing grants one Dice of the clothing's rarity.
A successful Lucky Scrap grants a second Dice, including when there is no
invested Essence to recover. Lucky Reward power affects recovered Essence,
not the number of Dice. Dice do not drop directly from lootboxes.

| Dice rarity | Weight |
| --- | ---: |
| E — Uncommon | 373 g |
| D — Rare | 806 g |
| C — Epic | 1,393 g |
| B — Legendary | 2,128 g |
| A — Mythical | 3,009 g |

Each Dice is a separate owned item. Inventory groups them by rarity under
**Consumables**, separately from Gems and Potions. They have no level, Aspect,
perks or equipment slot.

## Reroll

Choose one existing perk on owned clothing and consume one Dice of the same
rarity plus the current Essence fee. Clothing can be carried or equipped;
listed clothing must first leave the Marketplace. See the
[current Reroll fees](../../../assets/economy-settings.md#crafting).

The new perk replaces the chosen perk immediately. It must differ in type,
effect or condition, but its numerical roll may be worse. There is no preview
that lets a player reject the result after rolling. Other perks and clothing
properties keep their values. Crafting Quality improves the roll; terminal
perks are generated for the current clothing level. On Perfect clothing, the
replacement also receives the item's permanent maximum values.

The Reroll fee is spent and is not added to the clothing's invested Essence.
If no valid replacement can be generated, the item and resources stay intact.

## Merge And Trade

The saved recipe currently merges five Dice of the same rarity into one Dice
of the next rarity, from E → D through B → A. Admin can set the required count
and base Essence fee separately for each transition. [Merge Recipes](../../../assets/economy-settings.md#merge-recipes)
records the current values. Crafting Merging reduces the Essence fee, not the
ingredient count. Mythical Dice cannot merge further; listed ingredients must
first be cancelled. Successful merging is guaranteed and retries cannot spend
the ingredients twice.

Dice trade for Gold through ordinary Marketplace slots, seller fees and
proceeds claims. Each listing sells one Dice. Dice cannot be equipped,
scrapped, levelled up or used for clothing evolution; Gems own that action.
