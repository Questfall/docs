# Questfall product documentation

Follow the workspace [AGENTS.md](../AGENTS.md). Read [CONTRIBUTING.md](CONTRIBUTING.md)
before refreshing settings or preparing publication; local edits remain drafts
until Fedor authorizes documentation publication.

Document progression, RPG, consensus and economy mechanics. Daily tasks and their
changing rewards, Chat and Tracker are auxiliary app features: do not add separate
documentation pages or settings exports for them.

The numerical reference is `assets/economy-settings.md`, generated from
`.gitbook/assets/economy-settings.json` by `scripts/sync-settings.js` through the
supported API exporter. Keep credentials, raw Admin responses, user records and
audit details out of this repository. A local snapshot does not confirm current
production settings; the offline exporter check verifies its generated page only.
Refresh from activated production and review related prose examples before publication.
